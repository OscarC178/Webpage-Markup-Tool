Web Page Markup Tool, before and after

The same actions on the same test pages, once with the published version 1.1 and once with the rebuilt version 2.0. Every picture is a real screenshot from Chromium 158 with the extension loaded. Select any picture to enlarge it.

Status on 25 November 2026: version 2.0 is built but has not yet been through the full 16-check test run. Version 1.1 has: across 11 test sites its saved baseline is 102 passes, 49 fails and 14 checks that could not run. Treat the right-hand pictures as what the new build does in these specific cases, not as a finished test result.

How marks are drawnBoxes laid over the page at measured positionsPainted with the text, nothing added to the page
How a mark is found againBy the page's internal structure, which breaks when a site adds a banner or redesignsBy the words and their surroundings; if the words are gone it is listed as "not found", never drawn in the wrong place

SavingFour places wrote the whole list; two tabs could overwrite each otherOne queue does all the saving
