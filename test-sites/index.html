Test sites

Eleven fictional static sites for testing the Web Page Markup Tool. Machine-readable list: sites.json.

  1. News article (serif long-form)
    inline strong/em/a spans crossing sentence boundaries, pull quotes and figures, footnote anchors, drop-cap first letter, print stylesheet
  2. Documentation (sticky header, sidebar, anchors)
    sticky header and sidebar, hash URLs, pre/code blocks, tables, second page
  3. Single-page app (pushState)
    history.pushState navigation without reload, content rendered 300 ms late, same path with changing query string
  4. Infinite-scroll feed with live ticker
    MutationObserver churn from 1 s ticker, infinite scroll appending nodes, layout shifting below the fold
  5. Shop product page
    tabs with hidden panels, accordion, sticky basket bar, SVG gallery, spec table
  6. Dark analytics dashboard
    light-on-dark text, inner scroll container, position:fixed sidebar, yellow and red text clashing with markup colours
  7. Multilingual magazine
    CSS multi-column layout, RTL Arabic, CJK without spaces, emoji with ZWJ sequences, tiny and huge type, justified hyphenated text
  8. Forms and embeds
    inputs and textarea, contenteditable, same-origin iframe, open shadow DOM, details/summary
  9. Edge cases
    quote and apostrophe in ids, duplicate ids, CSS transform, horizontal scroll table, SVG text, user-select:none, 4000px+ page with body offsets, text replaced after 2 s
  10. PDF document
    embedded PDF viewer, links to PDF, extension cannot reach into PDF viewer
  11. Hostile CSS
    !important universal resets, transformed positioned zoomed body, max z-index fixed layers, rules matching toolbar/note names, gradient, pattern and clipped-text backgrounds, yellow/red text, print stylesheet
