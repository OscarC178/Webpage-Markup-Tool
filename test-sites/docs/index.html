Quillwork reference

Quillwork is a small, fictional static-site generator that turns a folder of Markdown files into a folder of HTML files. This page documents the command line, the configuration file and the programmatic API.

Installation

Quillwork needs Node.js 20 or later. Install it globally to get the quill command, or add it to a project as a development dependency so that every contributor builds with the same version. A global install is quicker for experiments; a local one is better for anything you intend to keep.

# global install
npm install --global quillwork

# or per project
npm install --save-dev quillwork
npx quill --version

If the final command prints a version number, you are ready to continue. If it prints command not found, check that your package manager's bin directory is on your PATH.

Configuration

Quillwork reads quill.config.json from the directory where you run it. Every key is optional; a missing file is the same as an empty object. Paths are resolved relative to the configuration file, not to the working directory, which is a common source of surprise when running from a subfolder.

{
  "source": "./content",
  "output": "./public",
  "baseUrl": "/",
  "plugins": ["quill-feed", "./local-plugin.js"],
  "minify": true
}

Environment variables

Any option can be overridden with an environment variable named QUILL_ followed by the option in upper case. For example, QUILL_OUTPUT=dist changes the output folder for a single run without touching the file.

Options reference

OptionTypeDefaultDescription
sourcestring"./content"Folder containing Markdown source files.
outputstring"./public"Folder the generated site is written to. It is emptied before each build.
baseUrlstring"/"Prefix added to every generated internal link.
pluginsstring[][]Package names or relative paths of plugins, run in order.
minifybooleanfalseRemove whitespace from generated HTML and CSS.
draftsbooleanfalseInclude files whose front matter sets draft: true.

API

The programmatic interface exposes a single asynchronous function, build(options), which resolves with a summary of what was written. It accepts the same keys as the configuration file, and merges them over the values that were loaded from disk, so a script can override just one setting. Errors are thrown as instances of QuillError, each carrying one of the codes listed below.

import { build } from "quillwork";

const summary = await build({ drafts: true });
console.log(`${summary.pages} pages in ${summary.ms} ms`);

Error codes

CodeMeaningUsual fix
Q001Source folder not foundCheck the source path.
Q014Invalid front matterLook for an unclosed quotation mark.
Q022Plugin threw during transformRun with --trace to see the stack.

Changelog

Version 2.4 added the drafts option and made output safe to point at a folder that does not yet exist. Version 2.3 fixed a long-standing bug in which relative links inside nested folders were rewritten twice. Earlier versions are summarised in the guide.
