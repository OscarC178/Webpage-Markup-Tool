Web Page Markup Tool: three icon options

Each is shown at the sizes Chrome uses: 128 px on the store, 48 px on the extensions page, and 16 px in the browser toolbar, on light and dark. The grey squares stand in for neighbouring extension icons.

A · Swipe

One highlighted letter. Says "marks up text" in one glance.

For
Strongest contrast in the browser toolbar; still reads as a yellow block with a letter at 16 px.
Against
A lettermark "A" is a common icon shape; less distinctive in a row of extensions.

B · Nib

A highlighter pen laying down a stroke. The literal tool, keeping the link to the current icon.

For
Closest to what people already recognise from version 1; shows the action.
Against
Most detail, so it is the weakest at 16 px: the pen becomes a dark diagonal.

C · Cursor

The tile itself is highlighter yellow, with a text cursor mid-selection. Says "select text, then mark it".

For
The yellow tile is recognisable by colour alone at any size; simplest shape.
Against
A text cursor can also read as "typing" or "rename"; least literal about highlighting.
